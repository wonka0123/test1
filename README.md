# SALECAL

패션 플랫폼의 행사 기간, 신청 마감일, 신청 여부를 한눈에 관리하는 캘린더 프로토타입입니다.

## 현재 기능
- 월간 캘린더와 플랫폼별 필터
- 행사 등록 / 수정 / 삭제
- 행사 기간과 별도 신청 마감일
- 마감 임박 및 마감 경과 표시
- 신청 완료 체크박스
- 공식 행사 URL과 메모

## GitHub Pages로 공개하기
1. 저장소의 **Settings** 탭을 엽니다.
2. 왼쪽 메뉴에서 **Pages**를 선택합니다.
3. **Build and deployment**의 Source를 **Deploy from a branch**로 선택합니다.
4. Branch는 **main**, 폴더는 **/(root)**로 설정하고 **Save**를 누릅니다.
5. 잠시 후 Pages 화면에 표시되는 공개 주소로 접속합니다.

## 중요한 제한 사항
현재는 정적 프런트엔드 데모이며, 행사 데이터와 신청 체크는 각 방문자의 브라우저에만 저장됩니다. 따라서 관리자가 등록한 행사가 다른 방문자에게 자동으로 공유되지 않고, 신청 체크도 기기 간 동기화되지 않습니다. 다른 사람의 행사 제보를 받고 공개 일정을 함께 관리하려면 데이터베이스와 관리자 인증을 추가해야 합니다. 개인 신청 여부는 로그인 사용자별 데이터로 분리해야 합니다.

현재 달력의 일정은 화면 테스트용 예시 데이터이며 실제 행사 일정이 아닙니다.
